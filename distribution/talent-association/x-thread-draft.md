# X thread draft — WAB Interview-to-Story field case

> Draft only. Not authorized for publication.

**1/10**

A transcript is not a story.

A translation is not localization.

An image prompt is not a visual system.

**2/10**

I am turning two editorial patterns in Dongguan—《即莞来》 and 《选择东莞》—into a public Agent Skill:

**WAB Interview-to-Story**

**3/10**

The workflow:

audio/notes → transcript → evidence ledger → story route → canonical story → multilingual editions → platform copy → visual brief → cards/posters → human publication

**4/10**

The sequence matters.

Every channel derivative returns to one evidence-linked canonical story.

Otherwise, five platforms can quietly create five versions of the truth.

**5/10**

Route 1: person story.

The person is irreplaceable. Facts and quotations must trace back to the interview. One person's experience cannot become proof of a group trend.

**6/10**

Route 2: place/choice story.

An interview can reveal the question, but current public sources must establish current city conditions, policy, projects, and services.

**7/10**

Natural English can change syntax and context.

It cannot change:

- factual certainty
- who acted
- quotation status
- whether something happened, is happening, or is only planned

**8/10**

Visuals start after the story is stable.

Real portraits, places, logos, quotations, and data need sources and rights. Generative imagery must not pose as documentary evidence.

**9/10**

The public package includes:

- Agent Skill
- schema + validator
- negative tests
- platform contracts
- visual handoff
- fictional sample

No raw interviews or performance claims.

**10/10**

The bounded claim:

One interview can become many assets. One approved truth should remain behind all of them.

Next: test it against prompt-only repurposing.

Where would this model overclaim?
